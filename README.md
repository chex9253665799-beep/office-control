# Панель офиса

Свой удалённый доступ и управление компьютерами офиса — как RuDesktop, только свой, бесплатный и без лимитов.

- **Свой сервер RustDesk** (открытый код) на твоём VPS — подключение к экрану любого ПК офиса, без ограничений по времени и без чужого облака.
- **Веб-панель** — все ПК списком: кто в сети, кто работает, загрузка процессора и памяти, место на дисках, программы, железо, серийные номера.
- **Подключение в один клик** — кнопка «Экран» открывает RustDesk сразу на нужном ПК (пароль подставляется сам).
- **Действия на один или сразу все ПК**: сообщение на экран, блокировка, перезагрузка/выключение, очистка, обновления Windows, перезапуск печати, установка/удаление программ, запрет флешек, блокировка сайтов, проверка на вирусы, своя команда PowerShell, отправка файлов.
- **Журнал** — кто и что делал.

## Как устроено

```
 ПК офиса (Windows)                     Твой VPS
 ┌───────────────────┐   HTTPS 8443   ┌──────────────────────────┐
 │ Агент офиса       │ ─────────────► │ office-panel (панель)    │ ◄── ты в браузере
 │ (SYSTEM, задача)  │                │                          │
 │ RustDesk (служба) │ ─ 21115-21117 ►│ office-hbbs / hbbr       │ ◄── RustDesk у тебя
 └───────────────────┘                └──────────────────────────┘
```

Агент — один PowerShell-скрипт (`C:\ProgramData\OfficeAgent`), работает от имени системы через Планировщик заданий.
Сам ставит RustDesk, направляет его на твой сервер, задаёт постоянный пароль, раз в 20 секунд отчитывается в панель и берёт задания.
Связь только с твоей панелью по HTTPS, сертификат панели проверяется по отпечатку.

## Установка сервера (1 раз)

В PuTTY на сервере (от root):

```bash
curl -fsSL https://raw.githubusercontent.com/chex9253665799-beep/office-control/main/server/install.sh | bash
```

В конце покажет адрес панели и пароль. Всё ставится в `/opt/office` отдельными службами — другие программы на сервере не затрагиваются.

- Обновить: `office-update`
- Сменить пароль панели: `office-passwd`
- Если у хостинга есть брандмауэр в личном кабинете — открыть: TCP 21115–21117, UDP 21116, TCP 8443.

## Добавить ПК

Панель → «＋ Добавить ПК» → скопировать строку → на ПК открыть **PowerShell от имени администратора** → вставить → Enter.
Через минуту ПК в панели, через пару минут — кнопка «Экран».

## Подключаться с твоего ПК / телефона

Панель → «Подключаться с моего ПК»: поставить RustDesk и вписать адрес сервера и ключ (показаны там же).

## Удалить агента с ПК

```powershell
Unregister-ScheduledTask OfficeAgent -Confirm:$false; Remove-Item C:\ProgramData\OfficeAgent -Recurse -Force
```

RustDesk удаляется обычным способом (Параметры → Приложения).

## Важно

- Работников стоит предупредить, что ПК обслуживаются удалённо (RustDesk показывает окно, когда к ПК подключаются).
- Строка установки содержит ключ подключения к панели — не публикуй её.
